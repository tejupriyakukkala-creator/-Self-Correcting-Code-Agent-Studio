Help & Documentation

How the Self-Correcting Agent Works

The agent operates via an autonomous 5-step feedback loop:
1. Code Generation: Converts natural language task descriptions into executable Python code with unit assertions.
2. AST Security Screening: Analyzes the AST tree to intercept hazardous modules or dangerous calls before execution.
3. Isolated Execution: Runs code in a isolated subprocess with strict execution timeouts.
4. Error Diagnostics: Captures STDOUT/STDERR tracebacks if assertions fail.
5. Self-Correction: Synthesizes execution feedback to rewrite and fix code until all tests pass cleanly.
